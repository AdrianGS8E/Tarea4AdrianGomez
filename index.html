Reconocimiento de Cubiertos

Este proyecto utiliza un modelo entrenado con Teachable Machine para reconocer tres tipos de cubiertos mediante la cámara: cuchara, cuchillo y tenedor.

Presione el botón para iniciar la cámara y muestre uno de los cubiertos frente a ella.
